Pusher

Pusher ابزاری ساده برای ارسال سریع پروژه به گیت‌هاب است. فایل زیپ پروژه، توکن و آدرس مخزن را وارد می‌کنید و برنامه محتوای زیپ را باز می‌کند و در قالب یک کامیت روی برنچ دلخواه می‌گذارد.

همه کارها داخل مرورگر شما انجام می‌شود و توکن فقط برای ارتباط مستقیم با API گیت‌هاب استفاده می‌شود.
