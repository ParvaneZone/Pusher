Pusher - PWA (Android / iPhone / Desktop)

1) All files of this folder go to the root of a GitHub repo (e.g. ParvaneZone/Pusher).
2) Repo Settings > Pages > Deploy from a branch > main / (root).
3) Open https://<user>.github.io/Pusher/ on the phone:
   Android (Chrome): Install button inside the app, or menu > Install app.
   iPhone (Safari): Share > Add to Home Screen.
